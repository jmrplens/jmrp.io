## Using Custom Components

### Callout Component

Use callouts to highlight important information (Full Width):

<Callout type="info" title="Info Title">
  This is an info callout. Available types: info, warning, error, success, tip, note.
</Callout>

### Tabs

Show multiple code examples or content side by side (Centered, ~70ch):

<Tabs>
  <TabPanel index={0}>
    ```javascript
    console.log('Hello World');
    ```
  </TabPanel>
  <TabPanel index={1}>
    ```python
    print("Hello World")
    ```
  </TabPanel>
</Tabs>

### BeforeAfter

Compare bad vs good code (Centered, ~70ch):

<BeforeAfter beforeLabel="Vulnerable" afterLabel="Secure">
  <div slot="before">
    ```javascript
    // Don't do this
    eval(input);
    ```
  </div>
  <div slot="after">
    ```javascript
    // Do this instead
    JSON.parse(input);
    ```
  </div>
</BeforeAfter>

### YouTube Embed

<YouTube id="VIDEO_ID_HERE" title="Video Title" />

### References

Don't add a References component or list yourself: cite sources inline with normal
markdown links (`[Nginx docs](https://nginx.org/...)`) and the layout collects them
into a References section at the end of the post automatically.
