<h2>About This Tool</h2>
<p>
  Inspect SSL/TLS certificates by fetching them from a URL or pasting
  PEM-encoded data. The tool decodes the ASN.1 DER structure entirely in your
  browser and provides a comprehensive analysis including a security assessment.
</p>
<h3>Information Displayed</h3>
<ul>
  <li>
    <strong>Validity status</strong> — valid, expiring soon, or expired with
    days remaining
  </li>
  <li>
    <strong>Subject &amp; Issuer</strong> — distinguished names with CN, O, C
    breakdown
  </li>
  <li>
    <strong>Subject Alternative Names</strong> — all DNS names, IPs, emails,
    URIs
  </li>
  <li>
    <strong>Public key</strong> — algorithm (RSA/EC/Ed25519), key size, curve,
    signature algorithm
  </li>
  <li>
    <strong>Key Usage &amp; Extended Key Usage</strong> — digital signature,
    server/client auth
  </li>
  <li>
    <strong>Authority Info Access</strong> — OCSP and CA Issuer URLs
  </li>
  <li>
    <strong>Certificate Transparency</strong> — SCT presence check
  </li>
  <li>
    <strong>SHA-256 fingerprint</strong> — computed in-browser via Web Crypto
  </li>
  <li>
    <strong>Security assessment</strong> — key strength, signature algorithm,
    validity duration, CT compliance
  </li>
</ul>
<h3>How to Use</h3>
<ol>
  <li>
    Enter a URL and click <strong>Fetch</strong> to download the certificate, or
    paste PEM data directly
  </li>
  <li>
    Click <strong>Inspect Certificate</strong> to decode and analyze
  </li>
  <li>Review all certificate details and security findings</li>
</ol>
<h3>Privacy</h3>
<p>
  All certificate parsing and analysis happens entirely in your browser. When
  fetching by URL, public CT log APIs are used (certspotter, crt.sh) — no
  server-side proxy. For private/internal certificates, use the PEM paste option
  or the <code>openssl</code> commands below.
</p>

<h3>Linux Command Reference</h3>
<p>
  You can inspect certificates from the terminal using
  <code>openssl</code>:
</p>

<h4>Download &amp; Save Certificate</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    echo | openssl s_client -connect jmrp.io:443 -servername jmrp.io 2>/dev/null | openssl x509 > cert.pem
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Saved to cert.pem">
    (certificate saved to cert.pem)
  </TerminalSessionOutput>
</TerminalSession>

<h4>Check Expiry (30 days)</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    # Check if certificate expires within 30 days (2592000 seconds)
    echo | openssl s_client -connect jmrp.io:443 -servername jmrp.io 2>/dev/null | openssl x509 -noout -checkend 2592000

    # Exit code 0 = OK, 1 = expiring soon
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Expiry Check">
    Certificate will not expire
  </TerminalSessionOutput>
</TerminalSession>

<h4>TLS Handshake &amp; Chain</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    echo | openssl s_client -connect jmrp.io:443 -servername jmrp.io 2>&1 | grep -E "Protocol|Cipher|Verify|depth"

  <TerminalSessionOutput title="TLS Details">

    depth=2 C=US, O=Internet Security Research Group, CN=ISRG Root X1
    depth=1 C=US, O=Let's Encrypt, CN=E7
    depth=0 CN=jmrp.io

    Protocol: TLSv1.3
    Verify return code: 0 (ok)
    ```
  </TerminalSessionOutput>
</TerminalSession>

<h4>Verify Certificate Chain</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    # Verify a certificate against the system CA bundle
    openssl verify cert.pem

    # Verify with explicit CA chain
    openssl verify -CAfile chain.pem cert.pem
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Verification">
    cert.pem: OK
  </TerminalSessionOutput>
</TerminalSession>

<h4>Monitor Expiry (cron script)</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    # Add to crontab: check daily, alert if expiring in 14 days
    for domain in jmrp.io example.com; do
    if ! echo | openssl s_client -connect "$domain:443" \
        -servername "$domain" 2>/dev/null | \
        openssl x509 -noout -checkend 1209600 2>/dev/null; then
        echo "WARNING: $domain cert expires within 14 days"
    fi
    done
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Expiry Monitor">
    (no output = all certificates OK)
  </TerminalSessionOutput>
</TerminalSession>
