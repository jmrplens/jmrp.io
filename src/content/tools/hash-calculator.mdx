<h2>About This Tool</h2>
<p>
  When you need to allow specific inline scripts in your CSP without using{" "}
  <code>'unsafe-inline'</code>, you can use hashes. This tool calculates the
  SHA-256 hash of your script content in the format CSP expects.
</p>
<h3>How to Use</h3>
<ol>
  <li>
    Paste your inline script content (excluding <code>&lt;script&gt;</code>{" "}
    tags)
  </li>
  <li>Copy the generated hash or full CSP directive</li>
  <li>
    Add the hash to your <code>script-src</code> directive
  </li>
</ol>
<h3>Important Notes</h3>
<ul>
  <li>Any change to the script (even whitespace) will change the hash</li>
  <li>
    For dynamic scripts, consider using
    <a href="/blog/003-implementing-content-security-policy-nginx/#solution-3-use-nonces">
      nonces
    </a>{" "}
    instead
  </li>

      the complete CSP guide
    </a>{" "}

  </li>
</ul>
