<h2>Acerca de esta herramienta</h2>
<p>
  Genera contraseñas fuertes y aleatorias usando el generador de números
  aleatorios criptográficos del navegador
  (<code>crypto.getRandomValues</code>). Elige entre contraseñas basadas en
  caracteres y frases de contraseña estilo Diceware para la máxima seguridad.
  El muestreo por rechazo elimina el sesgo modular para una aleatoriedad
  uniforme.
</p>
<h3>Características</h3>
<ul>
  <li>
    <strong>Aleatoriedad criptográficamente segura</strong> — usa la Web
    Crypto API con muestreo por rechazo
  </li>
  <li>
    <strong>Modos de contraseña y frase de contraseña</strong> — basado en
    caracteres o en palabras
  </li>
  <li>
    <strong>Estimación de entropía</strong> — bits de entropía calculados en
    tiempo real
  </li>
  <li>
    <strong>Estimación de tiempo de descifrado</strong> — cuánto tardaría un
    ataque de fuerza bruta a 1 billón de intentos/seg
  </li>
  <li>
    <strong>Excluir caracteres ambiguos</strong> — elimina 0, O, l, 1, I para
    evitar confusión
  </li>
  <li>
    <strong>Personalizable</strong> — longitud, conjuntos de caracteres,
    separadores de palabras, mayúsculas, añadir número
  </li>
</ul>
<h3>¿Cómo se usa?</h3>
<ol>
  <li>Elige entre el modo Contraseña o Frase de contraseña</li>
  <li>Ajusta la longitud y los conjuntos de caracteres (o cantidad de palabras/separador)</li>
  <li>Opcionalmente excluye caracteres ambiguos</li>
  <li>Haz clic en Generar o copia directamente al portapapeles</li>
</ol>
<h3>¿Es privado?</h3>
<p>
  Toda la generación de contraseñas ocurre completamente en tu navegador usando
  la Web Crypto API. No se transmite, almacena ni registra ninguna contraseña.
  Las contraseñas generadas nunca salen de tu dispositivo.
</p>

<h4>Usando pwgen</h4>
<p>
  <code>pwgen</code> es un generador de contraseñas dedicado disponible en la
  mayoría de distribuciones (<code>sudo apt install pwgen</code>). Soporta
  modos pronunciables y completamente aleatorios.
</p>

<TerminalSession>
  <TerminalSessionCommand>
    ```
    # Aleatorio seguro, 20 caracteres
    pwgen -s 20 1

    # Con símbolos
    pwgen -sy 20 1

    # Sin caracteres ambiguos (0O l1I)
    pwgen -sB 20 1

    # Pronunciable (más fácil de recordar)
    pwgen 16 1
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Contraseñas con pwgen">

  </TerminalSessionOutput>
</TerminalSession>

<h4>Cálculo de entropía</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    python3 -c "
    import math
    pool = 26+26+10+8  # A-Z, a-z, 0-9, símbolos
    length = 20
    entropy = math.log2(pool) * length
    years = (2**entropy / 1e12) / 31557600
    print(f'Pool: {pool} chars')
    print(f'Entropy: {entropy:.1f} bits')
    print(f'Crack time (1T/s): {years:.2e} years')
    "
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Análisis de entropía">
    ```
    Pool: 70 chars
    Entropy: 122.6 bits
    Crack time (1T/s): 2.53e+17 years
    ```
  </TerminalSessionOutput>
</TerminalSession>
