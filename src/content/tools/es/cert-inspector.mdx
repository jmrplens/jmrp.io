<h2>Acerca de esta herramienta</h2>
<p>
  Inspecciona certificados SSL/TLS descargándolos desde una URL o pegando
  datos codificados en PEM. La herramienta decodifica la estructura ASN.1 DER
  completamente en tu navegador y proporciona un análisis exhaustivo que
  incluye una evaluación de seguridad.
</p>
<h3>Información mostrada</h3>
<ul>
  <li>
    <strong>Estado de validez</strong> — válido, próximo a expirar o expirado,
    con días restantes
  </li>
  <li>
    <strong>Sujeto y emisor</strong> — nombres distinguidos con desglose de CN,
    O, C
  </li>
  <li>
    <strong>Subject Alternative Names</strong> — todos los nombres DNS, IPs,
    correos, URIs
  </li>
  <li>
    <strong>Clave pública</strong> — algoritmo (RSA/EC/Ed25519), tamaño de
    clave, curva, algoritmo de firma
  </li>
  <li>
    <strong>Key Usage y Extended Key Usage</strong> — firma digital,
    autenticación de servidor/cliente
  </li>
  <li>
    <strong>Authority Info Access</strong> — URLs de OCSP y CA Issuer
  </li>
  <li>
    <strong>Certificate Transparency</strong> — comprobación de presencia de SCT
  </li>
  <li>
    <strong>Huella SHA-256</strong> — calculada en el navegador mediante Web
    Crypto
  </li>
  <li>
    <strong>Evaluación de seguridad</strong> — fortaleza de clave, algoritmo de
    firma, duración de validez, cumplimiento de CT
  </li>
</ul>
<h3>Cómo usar</h3>
<ol>
  <li>
    Introduce una URL y haz clic en <strong>Obtener</strong> para descargar el
    certificado, o pega datos PEM directamente
  </li>
  <li>
    Haz clic en <strong>Inspeccionar certificado</strong> para decodificar y
    analizar
  </li>
  <li>Revisa todos los detalles del certificado y los hallazgos de seguridad</li>
</ol>
<h3>Privacidad</h3>
<p>
  Todo el análisis y la decodificación del certificado ocurren completamente en
  tu navegador. Al obtener por URL, se utilizan APIs públicas de logs CT
  (certspotter, crt.sh) — sin proxy del lado del servidor. Para certificados
  privados o internos, usa la opción de pegar PEM o los comandos
  <code>openssl</code> que se muestran a continuación.
</p>

<h3>Referencia de comandos Linux</h3>
<p>
  Puedes inspeccionar certificados desde la terminal usando
  <code>openssl</code>:
</p>

<h4>Descargar y guardar certificado</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    echo | openssl s_client -connect jmrp.io:443 -servername jmrp.io 2>/dev/null | openssl x509 > cert.pem
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Guardado en cert.pem">
    (certificado guardado en cert.pem)
  </TerminalSessionOutput>
</TerminalSession>

<h4>Resumen rápido del certificado</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```

    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Resumen del certificado">

  </TerminalSessionOutput>
</TerminalSession>

<h4>Comprobar expiración (30 días)</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    # Comprobar si el certificado expira en 30 días (2592000 segundos)
    echo | openssl s_client -connect jmrp.io:443 -servername jmrp.io 2>/dev/null | openssl x509 -noout -checkend 2592000

    # Código de salida 0 = OK, 1 = expira pronto
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Comprobación de expiración">
    Certificate will not expire
  </TerminalSessionOutput>
</TerminalSession>

<h4>Handshake TLS y cadena</h4>
<TerminalSession>
  <TerminalSessionCommand>


  <TerminalSessionOutput title="Detalles TLS">

    ```
    depth=1 C=US, O=Let's Encrypt, CN=E7
    depth=0 CN=jmrp.io

    Protocol: TLSv1.3
    Verify return code: 0 (ok)
    ```
  </TerminalSessionOutput>
</TerminalSession>

<h4>Verificar cadena de certificados</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    # Verificar un certificado contra el paquete de CA del sistema
    openssl verify cert.pem

    # Verificar con cadena CA explícita
    openssl verify -CAfile chain.pem cert.pem
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Verificación">
    cert.pem: OK
  </TerminalSessionOutput>
</TerminalSession>

<h4>Monitorizar expiración (script cron)</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    # Añadir al crontab: comprobar diariamente, alertar si expira en 14 días
    for domain in jmrp.io example.com; do
    if ! echo | openssl s_client -connect "$domain:443" \
        -servername "$domain" 2>/dev/null | \
        openssl x509 -noout -checkend 1209600 2>/dev/null; then
        echo "AVISO: el certificado de $domain expira en 14 días"
    fi
    done
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Monitor de expiración">
    (sin salida = todos los certificados OK)
  </TerminalSessionOutput>
</TerminalSession>
