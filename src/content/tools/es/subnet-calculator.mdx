<h2>Acerca de esta herramienta</h2>
<p>
  Un conjunto completo de herramientas de redes IP que cubre todo lo necesario
  para la planificación de direcciones IPv4 e IPv6. Cuatro calculadoras
  especializadas en una sola herramienta: calculadora de subredes, información
  de dirección, planificador VLSM y conversor de rangos a CIDR.
</p>

    calculados
  </li>
</ul>

<h2>Cómo usar</h2>

<h3>Calculadora de subredes</h3>
<ol>
  <li>
    Introduce una dirección IPv4 (p. ej., <code>192.168.1.0</code>) o IPv6
    (p. ej., <code>2001:db8::</code>)
  </li>
  <li>Establece la longitud del prefijo CIDR o haz clic en un botón de preset</li>
  <li>
    Consulta la dirección de red, broadcast, máscara, wildcard, rango de hosts,
    tipo de dirección y más
  </li>
  <li>
    Desplázate hacia abajo para ver la visualización de límite de bits que
    muestra los bits de red frente a los de host
  </li>
</ol>

<h3>Información de dirección</h3>
<ol>
  <li>
    Introduce cualquier dirección IP, entero o valor hexadecimal (p. ej.,{" "}
    <code>3232235777</code> = 192.168.1.1)
  </li>
  <li>
    Consulta todas las representaciones: binario, hex, entero, DNS inverso,
    IPv4-mapped IPv6 y 6to4
  </li>
  <li>Identifica el tipo, clase y ámbito de la dirección</li>
</ol>

<h3>Planificador VLSM</h3>
<ol>
  <li>
    Introduce una red IPv4 base (p. ej., <code>10.0.0.0/16</code>)
  </li>
  <li>
    Añade requisitos de subredes con nombres y número de hosts necesarios
  </li>
  <li>
    Pulsa Calculate para ver la asignación óptima ordenada por tamaño, con
    análisis de desperdicio
  </li>
</ol>

<h3>Rango a CIDR</h3>
<ol>
  <li>
    Introduce las direcciones IPv4 de inicio y fin (p. ej.,{" "}
    <code>192.168.1.0</code> a <code>192.168.3.255</code>)
  </li>
  <li>
    Consulta el conjunto mínimo de bloques CIDR que cubren el rango
  </li>
</ol>

<h2>Explicación de VLSM</h2>
<p>
  <strong>Variable Length Subnet Masking (VLSM)</strong> permite dividir una red
  en subredes de diferentes tamaños, minimizando el desperdicio de direcciones.
  El algoritmo:
</p>
<ol>
  <li>Ordena los requisitos por número de hosts (de mayor a menor)</li>
  <li>
    Para cada requisito, encuentra el bloque potencia de 2 más pequeño que
    encaje (hosts + 2 para direcciones de red/broadcast)
  </li>
  <li>Alinea el bloque a su límite natural</li>
  <li>Asigna y avanza al siguiente espacio disponible</li>
</ol>
<p>
  En IPv6, VLSM es menos relevante porque /64 es el prefijo estándar para todas
  las subredes (requerido para SLAAC). El inmenso espacio de direcciones hace
  innecesaria la variación de tamaños.
</p>

<h2>Algoritmo de rango a CIDR</h2>
<p>
  Convertir un rango de IP arbitrario a bloques CIDR encuentra el conjunto
  mínimo de prefijos que cubren exactamente el rango. Para cada posición:
</p>
<ol>
  <li>Encuentra el bloque alineado más grande que comience en la dirección actual</li>
  <li>Asegúrate de que el bloque no se extienda más allá del final del rango</li>
  <li>Registra el bloque y avanza más allá de él</li>
</ol>
<p>
  Esto es útil para reglas de firewall, agregación de rutas y listas de control
  de acceso donde se requiere notación CIDR.
</p>
