<h2>About This Tool</h2>
<p>
  Generate production-ready Nginx server block configurations with a visual
  builder. Select the features you need and get a complete configuration file
  you can copy directly to your server.
</p>

<h3>Features</h3>
<ul>
  <li>
    <strong>6 presets</strong> — Static, Reverse Proxy, SPA, PHP-FPM, API
    Server, Hardened
  </li>
  <li>
    <strong>Upstream blocks</strong> — Named upstream with load balancing
    (round-robin, least connections, IP hash), keepalive connections, and
    multiple backend servers
  </li>
  <li>
    <strong>Modern SSL/TLS</strong> — QUIC/HTTP3, OCSP stapling, 0-RTT early
    data, strong cipher suites, session tickets off, HSTS preload
  </li>
  <li>
    <strong>Access control</strong> — Rate limiting with burst, block hidden
    files, block exploit paths (wp-admin, phpMyAdmin), tarpit slow responses
  </li>
  <li>
    <strong>Security headers</strong> — X-Frame-Options, XCTO, Referrer-Policy,
    Permissions-Policy, COOP/CORP/COEP, basic CSP with link to
    <a href="/tools/csp-builder/">CSP Policy Builder</a>
  </li>
  <li>
    <strong>Performance</strong> — Gzip, Brotli, static asset caching, open file
    cache, proxy buffering
  </li>
  <li>
    <strong>Reverse proxy</strong> — WebSocket support, proxy headers,
    keepalive, buffering options
  </li>
</ul>

<h3>How do I use it?</h3>
<ol>
  <li>Start with a preset that matches your use case</li>
  <li>Customize domain, root path, and SSL certificate paths</li>
  <li>Enable QUIC/HTTP3, OCSP stapling, and modern TLS options</li>
  <li>Configure access control: rate limiting, blocked paths, and tarpit</li>
  <li>Toggle security headers and performance optimizations</li>
  <li>
    Copy the generated configuration and place it in your Nginx sites directory
  </li>
</ol>

<h3>Privacy</h3>
<p>
  All configuration generation happens entirely in your browser. No domains, IP
  addresses, or backend paths are transmitted to any server. Your server
  architecture stays private.
</p>
