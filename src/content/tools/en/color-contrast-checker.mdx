<h3>What Are the WCAG 2.2 Contrast Requirements?</h3>
<p>
  The Web Content Accessibility Guidelines (WCAG) 2.2 define four contrast
  thresholds based on text size and compliance level:
</p>
<ul>
  <li>
    <strong>AA Normal Text</strong> — minimum 4.5:1 ratio. Applies to text
    smaller than 18pt (24px) or 14pt (18.66px) bold.
  </li>
  <li>
    <strong>AA Large Text</strong> — minimum 3:1 ratio. For text 18pt+ (24px) or
    14pt+ bold (18.66px).
  </li>
  <li>
    <strong>AAA Normal Text</strong> — minimum 7:1 ratio (enhanced). Same size
    rules as AA.
  </li>
  <li>
    <strong>AAA Large Text</strong> — minimum 4.5:1 ratio. Enhanced level for
    large text.
  </li>
  <li>
    <strong>Non-Text (SC 1.4.11)</strong> — minimum 3:1 ratio. Applies to UI
    components (buttons, inputs, borders) and graphical objects that convey
    information.
  </li>
</ul>

<h3>APCA — The Next Generation</h3>
<p>
  APCA (Accessible Perceptual Contrast Algorithm) is being developed for WCAG
  3.0. Unlike WCAG 2.x which uses a simple luminance ratio, APCA accounts for
  human visual perception, including:
</p>
<ul>
  <li>
    <strong>Polarity sensitivity</strong> — dark text on light backgrounds is
    perceived differently than light text on dark backgrounds
  </li>
  <li>
    <strong>Font size awareness</strong> — the Lc value maps to recommended font
    sizes and weights
  </li>
  <li>
    <strong>Spatial frequency</strong> — thin fonts need more contrast than bold
    fonts
  </li>
</ul>
<p>APCA Lc value usage guidelines:</p>
<ul>
  <li>
    <strong>Lc ≥ 90</strong> — Preferred for body text
  </li>
  <li>
    <strong>Lc ≥ 75</strong> — Good for body text, perfect for large text
  </li>
  <li>
    <strong>Lc ≥ 60</strong> — Large text and headings only
  </li>
  <li>
    <strong>Lc ≥ 45</strong> — Large non-text elements only
  </li>
  <li>
    <strong>Lc ≥ 30</strong> — Non-text elements (icons, borders, dividers)
  </li>
  <li>
    <strong>Lc &lt; 15</strong> — Not usable for any purpose
  </li>
</ul>

<h3>Color Vision Deficiency</h3>
<p>
  Approximately 8% of males and 0.5% of females have some form of color vision
  deficiency. The simulation uses Brettel/Viénot transformation matrices to show
  how your color pair appears to people with:
</p>
<ul>
  <li>
    <strong>Protanopia</strong> (~1% of males) — missing red cone cells. Red
    appears dark, red-green differences are lost.
  </li>
  <li>
    <strong>Deuteranopia</strong> (~1% of males) — missing green cone cells. The
    most common form. Green-red confusion.
  </li>
  <li>
    <strong>Tritanopia</strong> (~0.003%) — missing blue cone cells. Blue and
    yellow are affected.
  </li>
  <li>
    <strong>Achromatopsia</strong> (~0.003%) — complete color blindness. Only
    luminance differences are perceived.
  </li>
</ul>
<p>
  Each simulation card shows the simulated contrast ratio so you can verify your
  colors work for all users.
</p>

<h4>How Do You Calculate the WCAG Contrast Ratio?</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    python3 -c "
    def lum(h):
        r,g,b = [int(h[i:i+2],16)/255 for i in (0,2,4)]
        r,g,b = [(c/12.92 if c<=0.04045 else ((c+0.055)/1.055)**2.4) for c in (r,g,b)]
        return 0.2126*r + 0.7152*g + 0.0722*b
    fg,bg = lum('1a1a2e'), lum('ffffff')
    ratio = (max(fg,bg)+0.05)/(min(fg,bg)+0.05)
    p = lambda ok: 'Pass' if ok else 'Fail'
    print(f'Ratio: {ratio:.2f}:1')
    print(f'AA Normal: {p(ratio>=4.5)}')
    print(f'AAA Normal: {p(ratio>=7)}')
    "
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Contrast Result">
    ```
    Ratio: 17.06:1
    AA Normal: Pass
    AAA Normal: Pass
    ```
  </TerminalSessionOutput>
</TerminalSession>

<h4>How Do You Batch-Check Multiple Color Pairs?</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    echo "1a1a2e:ffffff
    333333:f5f5f5
    ff0000:ffffff
    777777:ffffff" | while IFS=: read fg bg; do
    python3 -c "
    def lum(h):
        r,g,b=[int(h[i:i+2],16)/255 for i in(0,2,4)]
        r,g,b=[(c/12.92 if c<=.04045 else((c+.055)/1.055)**2.4)for c in(r,g,b)]
        return .2126*r+.7152*g+.0722*b
    l1,l2=lum('$fg'),lum('$bg')
    r=(max(l1,l2)+.05)/(min(l1,l2)+.05)
    ok='✓' if r>=4.5 else '✗'
    print(f'#$fg on #$bg → {r:.1f}:1 {ok}')
    "
    done
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Batch Results">

    #333333 on #f5f5f5 → 11.6:1 ✓
