<h2>About This Tool</h2>
<p>
  Convert between Unix timestamps and human-readable date formats. The tool
  supports bidirectional sync, automatic detection of seconds vs milliseconds,
  and comparison across <strong>11 timezones</strong>
  simultaneously.
</p>

<h3>Features</h3>
<ul>
  <li>
    <strong>Bidirectional sync</strong> — timestamp and date picker stay
    synchronized; editing either updates all outputs instantly
  </li>
  <li>
    <strong>Auto-detect seconds / milliseconds</strong> — automatically
    determines the unit based on digit count, with manual override
  </li>
  <li>
    <strong>Multiple output formats</strong> — Local time, UTC (ISO 8601), RFC
    2822, short date (YYYY-MM-DD), week number, and day of year
  </li>
  <li>
    <strong>Timezone comparison</strong> — view the same moment across 11 cities
    (New York, Los Angeles, Chicago, London, Berlin, Tokyo, Shanghai, Kolkata,
    Sydney) with your local timezone highlighted
  </li>
  <li>
    <strong>Live clock</strong> — current Unix timestamp updates every second
    with a "Now" button to instantly capture it
  </li>
  <li>
    <strong>Relative time</strong> — human-readable "time ago / from now"
    display that refreshes automatically
  </li>
  <li>
    <strong>Shareable links</strong> — timestamps are encoded in the URL (
    <code>?ts=...&amp;unit=...</code>) for easy sharing
  </li>
  <li>
    <strong>Copy buttons</strong> — one-click copy on every output value
  </li>
</ul>

<h3>How to Use</h3>
<ol>
  <li>
    Enter a Unix timestamp to see date, timezone table, and all formats update
    instantly
  </li>
  <li>
    Or pick a date and time — the timestamp input and all outputs sync
    automatically
  </li>
  <li>
    Click <strong>Now</strong> to capture the current timestamp
  </li>
  <li>
    Use the <strong>Auto / Seconds / Milliseconds</strong> toggle to control
    unit interpretation (Auto uses digit count heuristic: ≤10 digits → seconds,
    &gt;10 digits → milliseconds)
  </li>
  <li>
    Click <strong>Share Link</strong> to copy a URL that opens the tool with the
    same timestamp pre-filled
  </li>
</ol>

<h3>Auto-Detection Logic</h3>
<p>
  When the unit selector is set to <strong>Auto</strong> (default), the tool
  determines the unit based on the input magnitude:
</p>
<ul>
  <li>
    <strong>≤ 9,999,999,999</strong> (10 digits or fewer) → interpreted as{" "}
    <strong>seconds</strong>. This covers dates up to November 2286.
  </li>
  <li>
    <strong>&gt; 9,999,999,999</strong> (11+ digits) → interpreted as{" "}
    <strong>milliseconds</strong>. JavaScript's <code>Date.now()</code> returns
    13-digit millisecond timestamps.
  </li>
</ul>
<p>
  You can always override the auto-detection by selecting
  <strong>Seconds</strong> or <strong>Milliseconds</strong> manually.
</p>

<h3>Output Formats Reference</h3>
<ul>
  <li>
    <strong>Local Time</strong> — formatted using your browser's locale and
    timezone (<code>toLocaleString()</code>)
  </li>
  <li>
    <strong>UTC (ISO 8601)</strong> — <code>2025-01-15T10:30:00.000Z</code>— the
    standard for APIs, logs, and data interchange
  </li>
  <li>
    <strong>RFC 2822</strong> — <code>Wed, 15 Jan 2025 11:30:00 +0100</code>—
    used in email headers and HTTP dates
  </li>
  <li>
    <strong>Short Date</strong> — <code>2025-01-15</code> — ISO 8601 date-only
    format
  </li>
  <li>
    <strong>Week Number</strong> — ISO 8601 week number (W01–W53), useful for
    sprint planning and reporting
  </li>
  <li>
    <strong>Day of Year</strong> — ordinal day (1–366) with total days in the
    year, useful for Julian date references
  </li>
</ul>

<h3>Privacy</h3>
<p>
  All conversions happen entirely in your browser using JavaScript's built-in{" "}
  <code>Date</code> and <code>Intl</code> APIs. No timestamp data is transmitted
  to any server. The shareable link only encodes the timestamp in URL
  parameters.
</p>

<h3>Linux Command Reference</h3>
<p>Common timestamp operations from the terminal:</p>

<h4>Get Current Timestamp</h4>
<TerminalSession>
  <TerminalSessionCommand>date +%s</TerminalSessionCommand>
  <TerminalSessionOutput title="Unix Timestamp (seconds)">
    1739361234
  </TerminalSessionOutput>
</TerminalSession>

<h4>Timestamp to Date</h4>
<TerminalSession>
  <TerminalSessionCommand>
    date -d @1739361234 "+%Y-%m-%d %H:%M:%S %Z"
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Formatted Date">
    2025-02-12 12:53:54 CET
  </TerminalSessionOutput>
</TerminalSession>

<h4>Date to Timestamp</h4>
<TerminalSession>
  <TerminalSessionCommand>
    date -d "2025-02-12 12:53:54" +%s
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Unix Timestamp">
    1739361234
  </TerminalSessionOutput>
</TerminalSession>

<h4>Convert Between Timezones</h4>
<TerminalSession>
  <TerminalSessionCommand>
    TZ="America/New_York" date -d @1739361234 "+%Y-%m-%d %H:%M:%S %Z"
  </TerminalSessionCommand>
  <TerminalSessionOutput title="New York Time">
    2025-02-12 06:53:54 EST
  </TerminalSessionOutput>
</TerminalSession>

<h4>Milliseconds Timestamp</h4>
<TerminalSession>
  <TerminalSessionCommand>date +%s%3N</TerminalSessionCommand>
  <TerminalSessionOutput title="Unix Timestamp (milliseconds)">
    1739361234567
  </TerminalSessionOutput>
</TerminalSession>

<h4>ISO 8601 and RFC 2822</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    date -d @1739361234 --iso-8601=seconds
    date -d @1739361234 -R
    ```
  </TerminalSessionCommand>
  <TerminalSessionOutput title="Standard Formats">
    ```
    2025-02-12T12:53:54+01:00
    Wed, 12 Feb 2025 12:53:54 +0100
    ```
  </TerminalSessionOutput>
</TerminalSession>
