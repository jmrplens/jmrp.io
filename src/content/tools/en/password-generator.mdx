<h2>About This Tool</h2>
<p>
  Generate strong, random passwords using the browser's cryptographic random
  number generator (<code>crypto.getRandomValues</code>). Choose between
  character-based passwords and Diceware-style passphrases for maximum security.
  Rejection sampling eliminates modular bias for uniform randomness.
</p>
<h3>Features</h3>
<ul>
  <li>
    <strong>Crypto-secure randomness</strong> — uses Web Crypto API with
    rejection sampling
  </li>
  <li>
    <strong>Password &amp; passphrase modes</strong> — character-based or
    word-based
  </li>
  <li>
    <strong>Entropy estimation</strong> — bits of entropy calculated in
    real-time
  </li>
  <li>
    <strong>Crack time estimate</strong> — how long to brute-force at 1 trillion
    guesses/sec
  </li>
  <li>
    <strong>Exclude ambiguous characters</strong> — remove 0, O, l, 1, I to
    avoid confusion
  </li>
  <li>
    <strong>Customizable</strong> — length, character sets, word separators,
    capitalize, add number
  </li>
</ul>
<h3>How do I use it?</h3>
<ol>
  <li>Choose between Password or Passphrase mode</li>
  <li>Adjust length and character sets (or word count/separator)</li>
  <li>Optionally exclude ambiguous characters</li>
  <li>Click Generate or copy directly to clipboard</li>
</ol>
<h3>Is it private?</h3>
<p>
  All password generation happens entirely in your browser using the Web Crypto
  API. No passwords are transmitted, stored, or logged. Your generated passwords
  never leave your device.
</p>

<h4>Using pwgen</h4>
<p>
  <code>pwgen</code> is a dedicated password generator available in most
  distributions (<code>sudo apt install pwgen</code>). It supports pronounceable
  and fully random modes.
</p>

<TerminalSession>
  <TerminalSessionCommand>
    ```
    # Secure random, 20 chars
    pwgen -s 20 1

    # With symbols
    pwgen -sy 20 1

    # No ambiguous chars (0O l1I)
    pwgen -sB 20 1

    # Pronounceable (easier to remember)
    pwgen 16 1
    ```

<h4>Entropy Calculation</h4>
<TerminalSession>
  <TerminalSessionCommand>
    ```
    python3 -c "
    import math
    pool = 26+26+10+8  # A-Z, a-z, 0-9, symbols
    length = 20
    entropy = math.log2(pool) * length
    years = (2**entropy / 1e12) / 31557600
    print(f'Pool: {pool} chars')
    print(f'Entropy: {entropy:.1f} bits')
    print(f'Crack time (1T/s): {years:.2e} years')
    "
    ```
  </TerminalSessionCommand>
