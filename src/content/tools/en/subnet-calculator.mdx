<h2>What is VLSM?</h2>
<p>
  <strong>Variable Length Subnet Masking (VLSM)</strong> allows dividing a
  network into subnets of different sizes, minimizing wasted addresses. The
  algorithm:
</p>
<ol>
  <li>Sort requirements by host count (largest first)</li>
  <li>
    For each requirement, find the smallest power-of-2 block that fits (hosts +
    2 for network/broadcast addresses)
  </li>
  <li>Align the block to its natural boundary</li>
  <li>Allocate and advance to the next available space</li>
</ol>
<p>
  In IPv6, VLSM is less relevant because /64 is the standard prefix for all
  subnets (required for SLAAC). The immense address space makes variable sizing
  unnecessary.
</p>

<h2>How does range-to-CIDR conversion work?</h2>
<p>
  Converting an arbitrary IP range to CIDR blocks finds the minimal set of
  prefixes that exactly cover the range. For each position:
</p>
<ol>
  <li>Find the largest aligned block starting at the current address</li>
  <li>Ensure the block does not extend beyond the end of the range</li>
  <li>Record the block and advance past it</li>
</ol>
<p>
  This is useful for firewall rules, route aggregation, and access control lists
  where CIDR notation is required.
</p>
